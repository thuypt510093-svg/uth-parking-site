# Website demo đăng ký gửi xe trước UTH CS1

## Chạy trên máy tính
1. Cài Python 3.
2. Giải nén thư mục dự án.
3. Mở Terminal/CMD tại thư mục dự án.
4. Cài thư viện: `pip install -r requirements.txt`
5. Chạy: `python app.py`
6. Mở trình duyệt tại: http://127.0.0.1:5000

## Tính năng mô phỏng
- Bấm trực tiếp vào 4 vùng màu trên bản đồ hoặc nút khu vực.
- Điền thông tin đăng ký và tạo phiếu xác nhận.
- Nút in phiếu (dùng hộp thoại in của trình duyệt).
- Hiển thị mã QR đã cung cấp.
- Chọn sao và gửi đánh giá demo.

Lưu ý: Đây là prototype frontend; dữ liệu không được lưu vào cơ sở dữ liệu hoặc gửi đến UTH.
